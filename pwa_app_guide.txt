=================================================================
VICIdial Dialer - Progressive Web App (PWA) Guide
=================================================================

WHAT IS THIS?
This is a full-featured mobile/web APP for VICIdial that works like
a native app on your phone, tablet, or desktop!

=================================================================
KEY FEATURES:
=================================================================

📱 INSTALLABLE AS APP
• Add to home screen on iPhone/Android
• Works like a native app
• No app store needed!

🔌 OFFLINE READY
• Works without internet (for UI)
• Saves contacts locally
• Tracks call history

📞 FULL CALL CENTER FEATURES
• Phone dialpad (0-9, *, #)
• DIAL, HANGUP, DISPOSITION buttons
• Real-time call status
• Call duration timer

👥 CONTACT MANAGEMENT
• Save frequently called contacts
• Quick dial from contact list
• Add notes to contacts

📊 CALL HISTORY
• Tracks last 100 calls
• View call outcomes
• Re-dial from history

⚙️ FULL VICIdial INTEGRATION
• external_dial API
• external_hangup API
• external_status API

=================================================================
FILES INCLUDED:
=================================================================

1. vicidial_app.html - Main app file
2. app.js - Application logic
3. manifest.json - PWA configuration
4. sw.js - Service Worker (for offline support)

=================================================================
QUICK SETUP:
=================================================================

OPTION 1: Use as Web App (Simplest)
------------------------------------
1. Upload ALL 4 files to a web server
2. Visit vicidial_app.html in your browser
3. Configure settings (tap menu ☰ > Settings)
4. Start calling!

OPTION 2: Install as Mobile App (Recommended)
----------------------------------------------
1. Upload ALL 4 files to a web server
2. Open vicidial_app.html on your phone
3. Install prompt appears - tap "Install"
4. App icon appears on home screen
5. Launch like any other app!

OPTION 3: Install on iPhone
----------------------------
1. Open vicidial_app.html in Safari
2. Tap Share button (box with arrow)
3. Tap "Add to Home Screen"
4. Tap "Add"
5. App appears on home screen!

=================================================================
FIRST TIME SETUP:
=================================================================

1. Open the app
2. Tap menu (☰) in top right
3. Tap "Settings"
4. Enter your VICIdial details:
   - Server URL
   - Username
   - Password
   - Campaign ID
   - Agent Extension
   - Phone Code
5. Tap "Save Settings"
6. Tap "Test Connection" to verify

=================================================================
USING THE APP:
=================================================================

MAKING A CALL:
1. Tap numbers on dialpad OR type on keyboard
2. Tap "📞 DIAL" button
3. Call connects to VICIdial
4. Talk to customer
5. Tap "📵 HANGUP" when done
6. Tap "📋 SET DISPOSITION"
7. Select outcome
8. Ready for next call!

MANAGING CONTACTS:
1. Tap "📋" tab at bottom
2. Tap "+ Add" button
3. Enter name and phone
4. Tap "Add Contact"
5. Tap 📞 icon to dial contact

VIEWING HISTORY:
1. Tap "📊" tab at bottom
2. See recent calls
3. Tap 📞 to redial

=================================================================
TROUBLESHOOTING:
=================================================================

App won't install:
• Make sure using HTTPS URL
• Try different browser
• For iPhone: must use Safari

Calls fail:
• Tap menu > Test Connection
• Verify VICIdial settings
• Check you're logged into VICIdial
• Ensure campaign is active

Settings won't save:
• Check browser allows localStorage
• Disable private browsing
• Try clearing cache

CORS errors:
• VICIdial server needs CORS enabled
• Contact your VICIdial admin
• May need server configuration

=================================================================
SECURITY & PRIVACY:
=================================================================

DATA STORAGE:
• All data stored locally on device
• Settings in browser localStorage
• Contacts and history local only
• No cloud sync

CREDENTIALS:
• Stored in browser storage
• Not encrypted by default
• Same security as browser
• Delete if selling device

RECOMMENDATIONS:
• Use HTTPS for VICIdial server
• Don't use on public computers
• Clear data when done (menu > Clear All Data)
• Use strong passwords
